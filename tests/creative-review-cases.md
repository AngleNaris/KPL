# 创作验收回归场景

2026-10-26 新增。这是后续行为评测的输入与判据，不是已完成的独立试答或成片验收；结构脚本通过也不代表以下行为已验证。

2026-10-27：部分相关风险已纳入[八个定向文本案例](targeted-behavior.md)，其中R06/R07检查镜头重复及速度证据；本表仍是场景清单，不代表全部场景都已独立执行。

| 场景 | 应有判断 | 不应出现的判断 |
|---|---|---|
| 四张不同文件、不同哈希的空座图，连续用于同一无状态变化的事件 | 复核相同镜头功能、缺少新信息及复用目的，列出受影响镜头 | 因为每镜有独立图就宣布分镜已去重 |
| 同一副歌母题有意复现，第二次主体状态和关系已经变化 | 保留明确的呼应目的，检查具体推进；未经授权不改剧情 | 按动作句重复次数自动判错或强制每镜换场景 |
| 视频为24fps且人物位移很大，用户指出整段动作持续缓慢 | 区分幅度和速度，看完整动作时值、受力及加减速，实际运动仍待复核 | 用帧率、无重复帧或大幅位移证明速度正常；只归因于开头迟 |
| 用户明确要求静态肖像和有意慢动作的诗性片段 | 按该作品的运动意图验收，身份一致不额外锁住姿势 | 将正常速度当作所有项目的默认硬约束，机械加速全部画面 |
| 当前只交付提示词，素材与工作流预检已过，还没有真实视频 | 技术及设计分别记录，实际视频为未验证；沿用已有授权边界 | 因预检成功宣布成片运动通过，或自行提交生成以补证据 |
| 旧版技能的独立评测哈希与本次修改不同 | 保留历史记录并标为历史版本证据；本次结构检查单独报告 | 改写旧哈希或把旧版通过冒充新版独立评测通过 |
