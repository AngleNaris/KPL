# 改造说明

2026-10-22。这是重新设计后的单入口 skill，不是两份 SKILL 顺次拼接，也不是在个人技能目录的安装记录。

| 来源/问题 | KPL 的处理 |
|---|---|
| video-prompting 的模型索引和多模型写作章 | 删除其他视频专项；把时序、参考职责、动作、声音和修订迁到通用视频模块 |
| DirectorSKILL 的大流水线 | 按用户交付层级按需读取；保留视觉主旨、段落、调度、镜头功能、连续性、声音与剪辑入口/终态 |
| 模型默认值容易混入内容 | 格式层只说实际字段、标签、模式和参数边界，不规定审美或镜头写法 |
| 缺模型就追问 | 不阻塞通用稿；只有专用格式真的依赖信息时才核实 |
| 图生视频重造参考 | 仅写变化、必要锚点和保留项；不擅自继承参考未授权的属性 |
| MV 必须下拍起、小节末停、副歌整套换色 | 改为可选设计，允许跨拍、长镜与母题重现，色彩服从全片主旨 |
| ASL、景别/镜头数量比例被当审美判定 | 只作为可选预算与节奏估算，不能推翻已确认分镜 |
| 非叙事段落套角色压力变化 | 区分叙事目标/阻力和非叙事的音乐、图形、表演、空间演进 |
| 同主体覆盖经验扩到所有切镜 | 明确区分连续覆盖、正反打、跨场景、时间跳跃与意象剪辑 |
| 固定裁首尾、匹配剪辑单载体 | 删除盲裁首8尾12帧；按实际素材选入出点，允许多个匹配维度共存 |
| 身份字符串 30–50 词与固定动作预算 | 不作为普适阈值；用可核查设计锚点和状态继承，冲突时报告而非删戏 |
| 写实/相机参数默认压过媒介 | 动画、插画、平面、摄影按用户选择；只在需要时给相机数值 |
| 本地图片技能夹带执行层 | 不复制工具路由、网络/鉴权、机器路径、私有项目例子或浏览器脚本 |
| 图片迭代越改越多 | 明确生成/编辑、逐图职责、允许修改/保留项、准确文字与最小修订 |
| 上游旧图片参数 | 仅核对官方 2.5 Sunburst/Flare；不套旧 input_fidelity 默认 |

独立撰写的虚构例子仅用于文本行为评测；不携带用户的真实项目或私人笔记。模型官方文档只引用接口事实及必要语法，不捆绑其全文或示例媒体。

## 2026-10-23：轻量规格编排

入口新增按交付范围选择的状态流程与一次一项高影响决定的询问方式；未确认项可交草稿，明确批准的风格/资产直接复用。单一规格模板记录角色、场景、道具、镜头、模式、验收和局部变更，不引入复杂账本。

补齐风格→资产→制作分镜的前置关系；先按内容与真实能力选视频模式，再分配分镜图职责，普通遮挡不自动换模式，后登场角色保持入场顺序。图片编辑保留母版/最佳确认版，退化时回退并合并有效修改，避免最新退化图的串行累积。

本轮确认机制依用户需求独立撰写。公开 [grill-me 入口](https://github.com/mattpocock/skills/blob/5beb35b040e3de97e54fa9e386d7e42d15c295c2/skills/productivity/grill-me/SKILL.md) 在本次查阅版本仅转到 [grilling](https://github.com/mattpocock/skills/blob/5beb35b040e3de97e54fa9e386d7e42d15c295c2/skills/productivity/grilling/SKILL.md)；KPL 没有移植其原文、批量盘问或执行流程，不宣称实现某一指定版本。独立文本执行与审查证据另见行为评测，未调用真实图像/视频生成。

## 2026-10-26/27：验收与局部作用域

保留并纳入镜头功能、完整运动与三层证据的创作验收模块，沿用同一规格及已有授权边界；旧版评测保留原始哈希，不冒充新版行为验证。

自然语言引用放在实际使用的对象/时段旁，局部造型、材质与光照随引用说明，H3等固定字段仍遵守适配。图片模块补景别裁切与参考可见信息覆盖；视频模块补有需求时的画内文字出现、运动、驻留与消失。项目特定的运镜、帧数、色彩或字体选择不变成通用硬规则。

本轮增补均为独立文字规则；回归输入为虚构场景，不包含私人对话、真实项目、机器路径或生成素材。
