# 验证报告

初始验证：2026-10-22；规格流程与独立文本审查：2026-10-23。

## 结构与来源

命令：`node scripts/validate.mjs`。验证范围包括唯一入口、按需规格流程、单一规格模板、三个通用模块、仅指定的模型适配、UTF-8、仓库内链接、JSON示例、固定上游 commit、完整许可字节指纹和发布卫生。H3 保存样本另验字段顺序、首镜时间格式及帧对齐，并用错误字段/重复字段/首镜切点三个反例检查验证器会拒绝。规格用例和判据另有JSON形状/ID检查；原始输出与审阅记录用哈希核对一致性。

结构检查的具体组数、文件与链接数量以每次脚本输出为准；这些不是语义评测得分。此脚本只接受入口目前使用的平面 YAML 子集，不宣称是通用 YAML 解析器。skill-creator 的 quick_validate.py 已查看，但当前执行环境无可用 Python/PyYAML 运行时，未执行该脚本；Node 检查覆盖此入口实际 frontmatter 的相关要求。

公开引用的可达性检查命令：`node scripts/validate.mjs --links`，最新原始请求结果保存在 [link-results.json](../tests/link-results.json)。2026-10-27的21个URL中2个直连成功、4个OpenAI URL返回403、15个网络请求失败，因此该次--links退出码为1。另用GitHub连接器及网页读取交叉核对其余19个URL：11个GitHub资源及5个文档正文可读，3个BytePlus链接只返回动态外壳和标题；记录见[本轮交叉核验](../tests/link-crosscheck.json)。全部链接可达不代表完整正文或接口格式已验证；没有篡改原始403/网络失败，也不宣称自动链接检查全通过。历史核查另见[旧交叉记录](../tests/citation-review.json)。

H3 格式依据固定版本的官方原始资料，GPT Image 2.5 依据本次读取的官方 API 页面；完整 schema、字段边界和未确认项见各自适配及 [sources.md](sources.md)。Seedance 的部分 ModelArk 正文动态加载，本次只引用可确认的接口边界，不发布猜测的完整请求。
