## 引用存在性与格式事实

公开引用的可达性检查命令：`node scripts/validate.mjs --links`，请求结果保存在 [link-results.json](../tests/link-results.json)。2026-10-23本轮21个URL中17个HTTP成功，4个OpenAI官方URL对该Node请求返回403；这4页曾于2026-10-22用网页阅读工具成功读取正文并核对相关字段，见[交叉核查记录](../tests/citation-review.json)。没有把403改写为200，也不宣称自动链接检查全通过。HTTP状态只证明可达；动态外壳、访问限制和超时需单独解读，不冒充已读正文。

H3 格式依据固定版本的官方原始资料，GPT Image 2.5 依据本次读取的官方 API 页面；完整 schema、字段边界和未确认项见各自适配及 [sources.md](sources.md)。Seedance 的部分 ModelArk 正文动态加载，本次只引用可确认的接口边界，不发布猜测的完整请求。
