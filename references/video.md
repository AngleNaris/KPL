# 通用视频提示词

镜头时长和动作阶段用秒编排并对用户以秒汇报；帧率是单独确认的输出设置。只有目标模型接口确实要求帧对齐时才作技术转换，保留原始秒数，不以帧数替代创作意图或擅自改时长。

## 把已确认内容编成可见过程

开始前读取 [共同契约](../SKILL.md)。用户已经批准分镜时，以该分镜为输入契约，保留镜头数、顺序、台词和时间。若只有创作简报，需要全片结构才读 [导演策划](directing.md)，不为每条短提示强制策划流程。

按需要包含：主体与环境、媒介、起态、按因果顺序发生的动作、构图/运动、声音、终态、必要约束。一个短动作可用一段；动作链、多人交接或明确剪切用分段时间轴。模板是表达工具，不是模型 API 字段。

动作写成“谁在何处，以什么方式接触什么，导致什么结果”。保留完整链条：靠近→接触→受力/移交→反应→落定。后一个动作继承前一个动作的物体位置、数量和状态。遮挡后重现不能把人物、持物手或移动方向重置。

给定 5 秒时，根据实际动作分配时间并留出终态；不要为了简化自行删动作，也不要用延长时长解决已锁定的 5 秒。若一串复杂操作明显难以完成，指出具体冲突并给可选方案，仍将原稿与建议区分。时间分段是控制意图，不能承诺逐帧执行。

情绪可作为表演意图，配以能观察的视线、呼吸、手势、停顿和变化；不把任何情绪词全面禁用。单一主运动通常便于控制，但不是每个模型每条视频都只能一个动作的铁律。

## 根据输入只写必要部分

多镜项目先复用 [规格流程](spec-workflow.md) 中的镜头/资产与模式记录。模式是内容和实际控制面的决定：首帧包含主要主体与环境、后续主要连续变化时优先首帧；重要新主体/显著区域揭示使首帧信息不足时优先实际支持的全能/多资产参考。普通出画、遮挡后重现不自动触发换模式，也不能把后出现角色提前塞到首帧。先作此决定再指定分镜图职责；未核实能力只给建议/待决，不能假装平台已支持或自动改戏。

| 模式 | 文本应承担的职责 |
|---|---|
| 文生视频 | 建立需要模型创造的主体、空间、媒介与时序 |
| 图生视频 | 继承图片已经确定的设计与起始状态，重点写变化和保留项 |
| 首尾帧/关键帧 | 说明帧之间的连续变化和落点，按实际支持的帧槽位绑定 |
| 多参考 | 每个资产分配明确属性，排除无关继承；不把风格参考当人物来源 |
| 编辑 | 定位目标时段/对象及允许变化，保留成功的表演、构图和状态 |
| 续接 | 以已完成的终态开始第一项新行动，避免重演旧动作 |

画面锚点是实际输入，不是一个文件名就能建立绑定。对未见参考保留清楚的占位说明；交最终可执行稿前核对真实标签与顺序。

自然语言表面支持分段引用时，把素材标记放在实际使用的对象或时段旁，具体造型、材质与局部光照紧随该引用；开头只保留全片共同的风格、摄影和连续性要求。注明该处继承的属性与状态，不能让后续状态提前出现。保留真实 ID 与标记格式；这是内容作用域要求，不改变 H3 等适配的固定定义区、字段顺序或帧对齐首行，也不强制所有引用内联。

每镜保留真实资产版本与各参考的继承/排除职责，尤其区分角色设计、场景布局、道具和当前起态。既有已确认版本不随“最新文件”静默切换；图片回退后只复核相关镜头。用户只需单条提示词且内容已足够时，直接交文本，不展开整个资产流程。

参考的可见信息应覆盖本镜所需的设计细节；景别裁切与参考信息覆盖的检查见 [图片模块](image.md#多图职责草图与局部编辑)，不能只凭素材已绑定就认定细节充足。

## 对白与声音

画内文字有时序或动效要求时，逐项保留文字原文、出现时刻、运动、驻留与消失；参考图中已有文字不意味着它从视频首帧出现。字形/版式参考与文字的时间职责分别说明，未要求动效时不擅自添加。

文字对白保留原语言、逐字原文、说话人和先后顺序；旁白和画内说话分开。多人对话按原分镜安排，不因为生成难度自动变成单人独白。指定不说话的人不能继承另一人的口型。

若提供声音参考，明确是原样复用、只取音色、口型/表演节奏还是音乐；没有听清的词不猜。逐字台词可在制作说明保留为权威记录，最终模型稿按该表面已核实的音频引用方式编码，避免让文本和录音产生冲突的第二次表演。

音乐、对白、环境声、接触声和静音分别决定。未要求音乐就不增加配乐；需要字段时用该格式的无配乐表示。仅“无音乐”不等于全静音；用户指定全静音时，正文也不能残留脚步、风声或说话。只给提示词时无需主动拟定完整混音工程。

## 通用表达示例

```text
连续镜头，手绘纸片动画。起始时人物右手握着关闭的蓝色盒子。
0–1秒：左手掀开盒盖，右手托稳盒底。
1–3秒：左手取出唯一一枚纸星，抬至胸前。
3–5秒：左手把纸星放到桌面并松开；右手仍托住打开的盒子，停在这一终态。
固定构图。保留纸张纹理、人物造型和桌面布局。仅保留指定的纸片摩擦声，无配乐。
```

这是通用内容草稿，不声称任何模型有这些固定字段。外部时长为 5 秒；若用户未指定声音，不据此例强加摩擦声。

## 格式编译与修订

运动设计与实际结果按 [镜头与运动验收](creative-review.md) 分层复核。重点看完整动作的时值、受力及加减速，区分整体持续慢与开头迟；正常帧率、大幅位移和提示词中的速度目标不能作为实际运动通过的证据。只要文本时记录动态效果未验证，不额外生成小样。

多镜制作或恢复任务时，先从 [规格驱动执行](spec-workflow.md) 确定已完成依据、任务依赖和当前最小可执行步骤；完成单镜小样后再以真实视频、当前版本及正常播放速度验证，不凭静帧推断动作或剪辑通过。

只有用户明确模型和表面后，读对应 [Seedance 2.5](formats/seedance-2.5.md) 或 [MiniMax H3](formats/minimax-h3.md)。序列化只改标签、字段、语言和必要对齐语句，不改变镜头功能或事件。未知模型就交通用稿并说明专用格式待核。

修订先找具体机制：参考职责泄漏、起态不明、动作次序冲突、机位路径矛盾、声音归属错误或终态缺失。只调整导致问题的部分，保留成功部分。需要拆镜、换参考或改时长时列为建议，不能擅自执行。没有真实结果时不用“已修复画面”或“生成验证通过”。
