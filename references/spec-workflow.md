# 轻量规格流程与逐问澄清

2026-10-23，按用户的创作流程需求独立编写。先读 [入口](../SKILL.md)；本文件只在多阶段、多镜或确认依赖需要管理时加载。

## 一个规格，三种状态

先读取已有剧本、分镜、参考、批准记录及项目规范，复用有效结论。规格可采用 [creative-spec.md](../assets/creative-spec.md)，只保留当前相关项：意图/范围、时长画幅与风格、角色/场景/道具及版本和状态、镜头编号/起终态、参考职责、视频模式及理由、验收条件、未决问题。

- 已确认：明确记录用户选定的内容、适用范围及可核查依据；确认“角色A v2”不意味着场景、服装或所有后续版本也通过。
- 建议：代理提出的方向和默认候选，不能写成已锁定。
- 待决：缺失、冲突或变更后需复核的具体事项，说明影响哪个交付；没有信息就留空或写待决，不伪造资产路径、版本和确认日期。

一个文件或会话摘要就是事实源，不另建状态账本。只有本次项目写入已授权时才保存到项目；否则保持会话摘要。无需为了使用 skill 安装文件、创建目录或改项目配置。

## 每次只解决下一项关键决定

问之前判断：答案是否已在资料里？不同答案是否会改变当前结果？是否依赖尚未解决的上游问题？只把现在能决定且有影响的一项交给用户。把可读取的事实查清，不转嫁成询问。

提问包含一个主问题、推荐方向和短取舍。例如：“这组分镜按现有水彩样张锁定画法，还是先探索更硬朗的版画方向？推荐水彩，能复用已确认角色；版画需要复核其造型表现。”不要同时附带画幅、音乐、角色、镜头数等一串独立问题。推荐不是批准，回答只更新其明确涉及的范围。

用户停止询问时，不再追问或换一种方式要求同意；按已知条件给草稿并列出真正影响它的假设/待决项。没有实际输入、确认或平台能力证据时，不宣称可执行的制作稿已批准。用户只要单条提示词，资料足够就直接写，不要求完整规格或另行风格确认。

## 前置顺序与复用

### 规格 → 风格 → 资产

先明确本次作品或交付的范围，再确认风格参考/文字规范，随后锁定当前需要的角色、场景、道具。风格记录媒介、线条/纹理、色彩与光线逻辑以及每份参考只控制的属性。风格可以由文字明确确认，不强迫先生成一张图。

资产锁定至少说明：真实标识与版本、角色/场景/道具类别、已确认哪些属性、哪些不继承、确认依据。若用户只给候选图或文字描述，就记录真实状态，不伪造“v1 已批准”。已批准资产直接复用；只在本轮变更确实触及时提出局部更新。

场景同样是资产：空间拓扑、门窗/地标相对位置、尺度、光向、主色、材料和可变化状态。不同视角不应重新设计房间。道具要保持数量、形状、颜色、持有者和事件造成的状态变化。锁定的设计属性与随剧情变化的湿度、开合、摆放分开。

### 资产 → 分镜/模式 → 分镜图职责

可以提前做叙事段落或镜头构思草案；批量制作分镜之前，当前需要的风格和资产应已确认。不要为了走流程重做用户批准的分镜。先读取每镜起态、过程、终态与后入场信息，再决定视频模式，最后决定需要哪类分镜图：

| 内容判断 | 推荐模式与图像职责 |
|---|---|
| 首帧已覆盖主要主体、环境与所需设计信息，后续主要是连续变化 | 优先实际表面支持的首帧输入；分镜图承担精确起态/构图 |
| 重要新主体后入场、显著揭示新区域或首帧不足以交代关键设计 | 优先实际支持的全能/多资产参考；分镜图可作构图锚点，另绑角色、场景、道具资产 |
| 用户明确首尾落点或多个关键姿态，表面提供对应槽位 | 可采用首尾帧/关键帧，明确每张图的时间职责 |
| 没有可用图或模型未定 | 可先写通用文本草稿，模式为建议/待决，不猜专用字段 |

普通出画、遮挡后重现、轻微移位、可由已知资产推出的连续变化，不自动要求换多参考。后出现的重要角色不能提前塞进首帧破坏剧情；应独立提供其资产参考，保持规定的入场时刻。多参考也不代表每个资产都要在首帧出现。

模式名称与能力必须对应当前平台；全能参考不等于任何图生视频端点都支持。没有证据时说明所需能力并给待验证方案；若平台不支持，提出保持事件顺序的可选办法，不静默拆镜、提前入场或改戏。模型格式层只编码已选模式，不再做导演教学。

每镜最小绑定：`镜头ID｜起态→终态｜模式/理由｜实际资产ID与版本｜各参考职责｜确认状态`。图像输入槽位和资产职责不同：同一张场景母版可以跨镜复用，某张构图草图只约束一个镜头；未见附件就用待绑定占位，不冒充已上传。

### 分镜图提示词 → 视频提示词 → 验收

分镜图写当前静态状态和资产继承，动作过程放视频稿。图片未确认时可继续写明确标注的文本草案，不能声称草图已通过或已进入生成。视频编译保留已确认镜头、对白、时间、模式和引用职责，只在最后应用对应格式。

验收按规格列出的可观察条件核对；文本层检查与看过真实输出分开。用户只要提示词时，不发起生成、上传素材、付费或发布。

## 变更只使相关确认失效

用户改变规格时，简短列出改变项、受影响资产/镜头、哪些旧确认需要局部复核、哪些继续有效，再更新同一规格。例：角色A换外套只影响其服装资产及出现该外套的镜头，不自动重做场景、音乐和不相关镜头。

用户明确要求的变更是本次变更授权，但新提出的造型方案仍是建议，不能自行宣布用户选了某一版。若影响到原对白、时长或分镜顺序，明确冲突；不要以修订为名覆盖其确认。对不受影响内容继续工作，不让全片无故重来。

图像编辑的母版、最佳确认版和退化回退见 [图片模块](image.md)；导演与视频内容方法分别见 [导演](directing.md) 和 [视频](video.md)，避免在规格里复制整段提示词。
