# 用户规格格式（编辑器约定）

新版离线 HTML 与原生 `.kpldoc` 共用 `kpl-user-spec-v2` 数据契约，但分别由浏览器和原生编辑器显示。每个项目只选其中一个作为权威；HTML 导出是不会同步的查看副本。KPL 工具对旧 v1 保留原样只读，旧 HTML 自带的页面可能仍允许用户编辑；v2 原生编辑器不能直接打开 v1，不自动转换。Agent 写入或修改用户规格时必须按本格式书写；写入流程、授权与哈希核对见 [项目目录与版本](project-structure.md)。字段不全时留空（显示为“待确认”），不猜测、不补默认值。

## 字段

顶层只有 `schema`、`document_id`、`version`、`status`、`confirmation`、`revision`、`title`、`summary`、`global_settings`、`layout_aspect`、`assets`、`shots`，多一个或少一个字段都会被拒绝。`layout_aspect` 是节奏预览的画幅，写成 `宽:高`（如 `16:9`、`9:16`、`2.39:1`），未经确认时留空。当前编辑器空值会暂按 16:9 显示预览；这不是用户确认，不用于交付规格或布局验收。

每个资产只有三个字段：

| 字段 | 含义 |
|---|---|
| `id` | 稳定标识，字母或数字开头，只含字母、数字、`_`、`-`，如 `A03` |
| `name` | 显示名，如 `厨师` |
| `path` | 必须位于 `../05_参考资产/` 内的图片（png/jpg/webp/gif），按 [项目目录](project-structure.md) 命名；编辑器无法为 webp 生成缩略图，只显示占位，文件本身仍有效 |

每个镜头只有以下字段，除 `layout_camera` 外全部是字符串：

| 字段 | 表格列/侧栏 | 写法 |
|---|---|---|
| `id` | — | 稳定标识；不得用行号或镜号代替身份 |
| `number` | 镜号 | 显示编号，不可重复 |
| `duration_seconds` | 时长 | 大于零的秒数，**最多 1 位小数（精确到 0.1 秒）**，如 `2.5`、`3`；未决定时留空。不得写 `1.75`、`1.4166666666666667` 这类值，检查脚本与编辑器都会拒绝。按帧数或音乐节拍换算时，先算各镜累计结束时间并取 0.1 秒整，再用相邻切点相减得到时长（最短 0.1 秒），不要逐镜四舍五入，否则总长会漂移 |
| `thumbnail` | 画面 | `../05_参考资产/` 内的参考画面；没有就留空 |
| `content` | 一句话内容 | 一句话写剧情或画面，不写摄影机运动 |
| `shot_scale` | 景别 | 如 `中近景` |
| `camera_motion` | 镜头运动 | 只写摄影机运动，人物动作不算；不动写 `固定` |
| `description` | 侧栏·详细描述 | 只概括这个画面里有什么：主体、动作、场景与光线，按下文引用资产、标记分段。**显示字数不超过 300 字**（不计 `{类别:}` 标记），检查脚本会拒绝超长描述。不写镜头功能、采用窗与稳定 ID、运镜原文、起态/终态长段、相邻镜关系、模型参考路径、工作流、来源与验收记录：这些是 Agent 的工作记录，放在项目状态文件里，不写进用户规格的任何字段 |
| `prompt` | 侧栏·图片生成提示词 | 图片生成用提示词，按下文引用资产、标记分段 |
| `video_prompt` | 侧栏·视频提示词 | 视频生成用提示词，按下文引用资产、标记分段；写法见 [通用视频提示词](video.md) |
| `mark` | 标记 | 空、`done`（完成）、`revise`（待修改）、`wip`（进行中）、`question`（有疑问）、`hold`（搁置） |
| `layout_camera` | 时间线·节奏预览 | `null`，或预览运镜对象，见下文 |

`mark` 由用户在编辑器中设置。Agent 只在用户明确要求时修改，不能凭自己判断把镜头标为完成。

镜头在数组中的顺序就是成片顺序。用户可以在编辑器时间线上拖动调整顺序和时长，调整顺序后显示镜号按新顺序自动重编（沿用原有前缀与位数），稳定 `id` 不变。Agent 读回后先按稳定 ID 核对顺序及外部镜号引用，不按旧行号覆盖。当前编辑器把待定时长镜头拖入时间线时会写入 2 秒：没有该镜时长的用户决定来源时，这只是占位，必须提问并保持相关结论未验证；不能因为文件里出现数字就认定已确认。

## 引用资产

在 `description`、`prompt` 与 `video_prompt` 中用 `@{资产}` 引用资产。优先写 ID，如 `@{A03}`；也可以写名称、文件名或不带扩展名的文件名，但必须只对应一个资产。引用的资产须先登记到 `assets`；未登记或对应多个资产时，编辑器会把它标成警告。同一镜头的“关联资产”与资产数，就是描述和两类提示词中已解析引用的并集（去重），不另外维护列表；数量不是实际上传或验证证据。

语法与 ShadowStage 的 `@{…}` 一致，可直接复用；`<Picture N>` 只在目标模型确实需要时保留。


## 分段标记

`description`、`prompt` 与 `video_prompt` 中的内容可用 `{类别:内容}` 标出分段。分段只为方便阅读：编辑器不显示标记，只显示内容，并按类别低饱和染色；悬停时整段高亮，提示类别名；用户复制时只得到纯文字。用户解锁后可选中文字、右键改类别，Agent 读回时以文档中的实际标记为准，不要覆盖用户改过的分段。类别只有四个：

| 类别 | 放什么 |
|---|---|
| `镜头` | 景别、机位、角度、运镜等摄影机信息；在 `description` 中最多用一个短语，完整运镜写进 `prompt`/`video_prompt` |
| `风格` | 画风、质感、光线、色彩、氛围 |
| `场景` | 地点、环境、陈设、天气等静态画面 |
| `动态` | 人物与物体的动作、变化 |

写法要求：

- 分段直接嵌在自然句子里，段与段之间用正常标点衔接；不要写 `景别：中近景` 这类可见标签，也不要用 `|`、`｜` 分隔。
- 冒号用半角 `:`，标记内不要再出现 `{`、`}`；分段内可以有 `@{…}` 引用，不能嵌套分段。
- 每段只标一个类别。归不进四类的文字不加标记，照常显示、不染色；不为凑格式编造内容。
- `镜头` 段的景别、运镜须与表格中的 `shot_scale`、`camera_motion` 一致。
- 把提示词交给生成模型前，去掉标记只保留内容（`{镜头:中近景}` → `中近景`）；引用标记按目标模型的格式适配处理。

示例：

```json
{
  "id": "stable-s02", "number": "S02", "duration_seconds": "3", "thumbnail": "",
  "content": "厨师在灶前翻炒，锅铲轻碰锅沿。", "shot_scale": "中近景", "camera_motion": "固定",
  "description": "{动态:@{A03} 站在 @{A05} 前翻炒，手中的 @{A04} 轻碰锅沿}，{场景:蒸汽在灯下升起}。",
  "prompt": "{镜头:中近景，略俯拍，固定机位}，{动态:@{A03} 在 @{A05} 前翻炒}，{风格:顶光与蒸汽逆光，胶片颗粒}",
  "video_prompt": "{镜头:中近景，固定机位}，{动态:@{A03} 连续翻炒两下，锅铲轻碰锅沿}，{场景:蒸汽上升}",
  "mark": "",
  "layout_camera": null
}
```

编辑器显示为：中近景，略俯拍，固定机位，@{A03} 在 @{A05} 前翻炒，顶光与蒸汽逆光，胶片颗粒。

## 节奏预览运镜

编辑器时间线上方的预览按真实时长依次播放每镜的 `thumbnail`（没有就显示合成占位）和一句话内容，用来在实际生成素材前检查节奏与时长。编辑器的表格与预览用的是宽 480 像素的缓存缩略图（见 [原生编辑器](native-editor.md)），清晰度低于 `layout_preview.py` 按原图生成的预演，不能据此判断裁切后的细节。`layout_camera` 让 Agent 为预览设定二维运镜，格式与 [layout 预演](layout-preview.md) 清单中的 `camera` 相同：

```json
{"layout_camera": {"type": "linear", "start_crop": [0, 0, 1, 1], "end_crop": [0.15, 0.15, 0.85, 0.85]}}
```

- 裁切框为相对参考画面的 `[左, 上, 右, 下]`，范围 0–1 且有正面积；`linear` 在镜内从起始框线性变到结束框，可表现推拉与平移；`static` 的两个框必须相同。
- 裁切后按比例放入画幅，不足处留黑边，不生成画外内容；只有硬切，不模拟人物动作、景深或三维运镜。
- 运镜应与 `camera_motion` 一致：例如“缓慢推近”用逐渐缩小的裁切框，“横移”用平移的裁切框。`camera_motion` 未确认或为 `固定` 时写 `null` 或 `static`，不静默套默认运镜。
- 通过 `html_spec.py apply` 写入：`{"target":"shot","id":"实际稳定ID","field":"layout_camera","old":null,"new":{...}}`；`old` 必须等于当前值。
