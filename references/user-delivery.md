# 用户可读交付与提示词语言

本页只规定表达与交付，创作规格仍只有一个。**用户查看或编辑的项目文档和报告不交付 `.md` 文件**；技能说明与 Agent 内部记录可继续用 Markdown/JSON。新项目优先使用 [`.kpldoc` 原生编辑器](native-editor.md)，已有 HTML 规格继续保持原样；旧项目中的 `.md` 可作为内部输入读取，不擅自迁移或改名。不能用重命名扩展名或展示一份与规格脱节的副本冒充完成。

当项目当前规格是可编辑 HTML 时，其权威内容保存在该用户文件里，Agent 工作区只记引用、任务和派生证据。页面默认阅读，进入编辑后需选择当前项目中的同名、内容一致文件，再点击保存并按浏览器提示授权；保存前核对磁盘字节，写入关闭后再读回核对，冲突或失败时保留未保存状态。浏览器不能确认同名同内容副本所在目录，用户须核对位置；底层接口不提供原子比较并写入，极短的并发写入窗口仍无法完全排除，重要编辑避免同时由两个进程保存。没有 File System Access 能力或权限时明确说明；用户可主动另存副本，但触发下载不等于原项目已更新。不能用 localStorage、下载提示或工具自述冒充写回成功。由 `.kpldoc` 导出的只读 HTML 没有这个编辑写回能力，也不会同步原文件。

选好当前文件后，用户可主动点击“记住此文件，下次继续编辑”：浏览器仅在本地 IndexedDB 保存该单文件句柄、当前页面地址与文档标识的关联及上次保存的文件哈希，不保存未提交编辑。刷新或重开后先查询权限，不自动请求；用户确认页面位置未变并点击继续后，才按浏览器需要请求授权，并重新核对文件、版本和哈希。复制或移动页面、同名副本、文件被更改或权限被撤销时，应重新核对并在需要时重选；`file://` 的本地存储和权限是否持久取决于浏览器，不能保证免授权。用户可“忘记文件关联”；这会清除应用记录并断开当前页，不自动撤销浏览器曾授予的权限。存储不可用或清除失败时说明具体状态，不把缓存当成已保存。

## 提示词语言

本用户的自然语言提示词默认中文，包括在线平台和本地模型；本地运行不自动等于英文。保留用户原文、台词及画面文字；模型名、接口参数、真实引用标记及确实要求原样的字段名保持原样。只在用户明确指定另一语言，或核实当前实际模型/平台的协议确实要求某部分英文时使用该部分英文，标明依据与范围；资料不清时先问，不凭英文示例猜协议。

在线生成按 [视频路由](video.md#先选生成方式)默认交可直接粘贴的中文自然语言正文，用户明确指定语言时遵照其要求；本地 MiniMax H3 才走其专项规范。区分提示正文、供人理解的设计参考、实际需要上传的素材清单、平台设置及验收/待决项。只给用户要求的内容：用户只要一条提示词时直接交正文，不强制附全套清单。用户未授权实际上传或生成时，不称已上传、已绑定或已生成。模型必须读到的引用标记仍留在正文，不能为了整洁删掉。

## 人读起来顺畅

先写画面发生什么，再写必要的机位与声音；动作按起态、变化、终态和秒数组织，不堆抽象形容或同义重复。角色首次用易懂称呼加唯一 ID，例如“店员（角色 A）”，后续用清楚的称呼；ID 与实际映射保持稳定，不因可读性悄悄换身份。分镜表优先展示镜号、时长（秒）、人物/画面、动作与必要切点；参考职责、设置、问题和验收只在相关处单列。不要把长串哈希、机器任务字段、日志和内部术语塞进每条提示词或用户报告；需要核查时在内部状态保留可追溯映射。

交付前用读者视角检查：能否一眼知道谁在做什么、何时发生、哪些文字能直接复制、实际要上传什么、哪些参数尚未设置、哪些结果尚未验证；对照原始要求核查遗漏与越权新增。看不懂的缩写、无用途的重复项和冲突句需要改写，关键约束及模型必需标记不能为了简短而删除。
