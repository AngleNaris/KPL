# KPL 编辑器界面

零依赖的 HTML/CSS/JS，由 `../build.py` 内联进单个模板后嵌入 WebView2 原生外壳（CSP：仅内联脚本与样式，图片只允许 `https://kpl-thumbs.local`，页面不能直接载入原图；音视频只允许 `https://*.kpl-media.local`）。数据契约为 `kpl-user-spec-v2`，加入媒体后为 `kpl-user-spec-v3`，Agent 写文档的格式见 `references/spec-format.md`。

## 预览

`index.html` 内嵌的是合成的 v3 示例数据（S02、S04、S06 关联了视频）；如需预览占位图与测试视频，可用已安装的 Pillow 与 ffmpeg 运行 `python -I make_preview_assets.py`，生成的图片标有“合成占位”，视频是彩条测试图，都不属于项目素材。预览环境按文件名从 `preview-assets/` 读视频；视频要能拖动定位，静态服务须支持 Range 请求。浏览器预览环境须由使用者明确选择；本流程不会自行启动服务或安装依赖。预览模式下保存只提示未连接保存程序，不写任何文件。

## 已定约定

- 外观：全局直角；深色/浅色/跟随系统 × 钨丝琥珀/录制红/示波青/冷光蓝，取值全部在 `tokens.css`。
- 焦点：内部底边指示条 + 底色，不使用 outline 或外环；编辑区（单元格、描述与提示词）的底线收细为 1px。选中行只用底色，不加侧边描边。
- 表格：缩略图、镜号、时长、一句话内容、景别、镜头运动、资产数（汇总值，只读）、标记。解锁后直接在单元格中编辑。
- 解锁不得改变布局：只读与编辑共用同一套元素（无边框输入框、固定尺寸的标记按钮、描述与提示词的 `.rich` 编辑区），只切换 readonly/tabindex/contenteditable；不为可编辑区域加框或提示文字。行内的 @{…} 用 span[role=button]，因为原生 button 不能跨行断开。
- 编辑模式靠全页面特效提示，全部无彩色：中性灰取景器角标停在四角；进入时一道白色斜向闪光自左上划向右下，星芒沿路径依次闪烁，退出时反向。系统开启“减少动态效果”时不播放闪光和星芒。
- 侧边栏只放表格里没有的内容：详细描述、关联资产、图片生成提示词、视频提示词。详细描述标题旁显示显示字数 `n/300`（不计分段标记，与 `scripts/html_spec.py` 的 `DESCRIPTION_LIMIT` 一致），超出时变警告色并在 title 提示；编辑器不拦保存，上限由 agent 端检查执行。
- 标记：单选，`done | revise | wip | question | hold`，空字符串表示未标记；只在解锁后可改。
- 资产引用沿用 ShadowStage 的 `@{…}` 语法，可写资产 ID、名称、文件名、主名或路径；唯一匹配才算解析成功，没有匹配或有歧义都标警告色。关联资产 = 描述与提示词中所有已解析引用的并集（去重）。
- 素材预览：悬停或聚焦 `@{…}` 时显示缩略图，点击复制图片位图。原生环境通过宿主消息 `copyImage` 完成；预览环境用 `navigator.clipboard`。悬停表格缩略图时用同一浮层显示大图（`.peek-large`）与一句话内容；悬停详情栏的视频行（整行 `.video-file[data-peek-video]`，有与资产卡片相同的底色反馈）时，浮层里的 `#peek-video` 静音播放该视频的采用范围，到出点回到入点循环，移开即停止并释放。
- 图片的来源是 `../05_参考资产/`，但页面不直接载入原图：原生宿主只在内部读取该目录（用于生成缩略图和复制位图），页面只能载入只读虚拟主机 `https://kpl-thumbs.local/` 上的缩略图（见下一条）。缩略图或资产不可用时不能把占位画面当真实素材。
- 缩略图：界面只载入宿主生成的缩略图，统一经 `thumbUrl()` 取地址（表格、时间线胶片条、侧栏资产卡、悬停预览、监视器都走它）。宿主在 `ready` 后后台生成并发 `thumbs` 消息（`done`、`total`、`finished`、`ready` 为“规格里的原路径 → 缓存文件名”），页面只认 `ready` 里出现过的图，未就绪的一律不载入、只留占位，随后由 `applyThumbs` 原地替换占位并补上胶片条，不重绘整个界面。进度显示在状态栏的 `#thumb-progress`；缓存本来就齐全时不提示。预览环境没有宿主缓存，沿用原图路径。
- 品牌：顶栏左侧是矢量横版标识，写在 `index.html` 图标精灵的 `<symbol id="i-logo">` 里（`KPL_LOGO_START/END` 标记之间，由 `../assets/trace_logo.py` 从 `logo-wide-src.jpg` 描摹生成，勿手改）。标识无底色，三层填充读 `tokens.css` 的 `--logo-1/2/3`（由 `--accent` 与 `--text` 混合得出），随深浅模式和主题色变化。程序图标 `kpl.ico` 由 `../assets/make_icon.py` 从 `logo-square-src.jpg` 生成。重新生成后要重新构建并更新清单。
- 关于与更新：顶栏右侧“关于”弹层（`#about-panel`）显示版本、作者与仓库，并声明启动时会静默检查更新；宿主发现新版本后显示 `#update-badge`。预览环境没有宿主，两者只显示占位。

- 分段染色：只按 agent 写入的 `{类别:内容}` 标记（镜头、风格、场景、动态）决定，编辑器隐藏标记、只显示内容；四类各一种低饱和文字色（`--seg-*`），素材引用保留强调色；悬停整段铺同色淡底并以 title 提示类别。没有标记的文字不染色。
- 改类别：解锁后选中文字再右键，弹出与标记菜单共用的 `#popup-menu`（镜头/风格/场景/动态/清除类别）；选区成为一个分段，跨过的旧分段被切开，只选到半个 `@{…}` 时扩到整个引用。只读或没有选中文字时保留系统右键菜单。
- 复制与剪切：选区在描述或提示词内时只写入 `text/plain`，不带分段标记，也不带 Chromium 默认附带的 HTML 样式。
- 描述与提示词：只读与编辑共用同一个 `.rich` 元素，解锁只加 `contenteditable="plaintext-only"`。编辑中分段结构以现有 span 为准（不从文字重新解析，输入到一半的 `@{` 不会拆散分段），只在引用变化时重新识别；输入法组字期间不重绘。
- 动效：每个交互都有对称的进入与退出（弹层与菜单用 `allow-discrete` + `@starting-style`，视图与侧栏交叉淡化）；“减少动态效果”下统一缩短为 1ms。
- 未保存提示：切换只读或关闭窗口时弹出 保存/放弃/取消 对话框；宿主关闭前调用 `window.__kplRequestClose()`，用户选定后页面发 `closeApproved`。
- 宿主消息：`ready`、`save`/`saveResult`、`prefs`（写入 `%LOCALAPPDATA%\KPL\prefs.json`）、`copyImage`/`copyResult`、`closeApproved`；宿主发给页面的还有 `info`（版本号）和 `update`（发现新版本），页面只会回 `openUpdate` 请求打开固定的发布页，网址不由页面决定。
- 偏好：`mode`、`accent` 与布局尺寸 `panelH`（时间线面板高度，默认取最小值 200px）、`asideW`（详情栏宽度），宿主只保存白名单内的键；窗口大小 `winW`/`winH`/`winMax` 只由宿主在关闭时写入（默认约 16:9），页面发来的同名键被忽略，两边写入都与现有文件合并。预览环境存在 `localStorage` 的 `kpl-prefs`。
- 时长：写入只允许最多 1 位小数（`DURATION_PATTERN`）。打开旧文件时 `normalizeDurations` 按累计切点取 0.1 秒整再相减（最短 0.1 秒，总长不漂移），只改工作副本并标为未保存，状态栏说明改了几镜；解锁并保存后才写回。已确认或定稿的版本不规整。
- 界面不放常驻提示文案：说明只在左下角状态栏；时间线的说明与快捷键收在工具条的问号按钮 `#help-trigger` 弹层里。
- 时间线视图按剪辑软件布局：上方监视器（画面按画幅等比放入并居中）、可上下拖动的分隔条 `#splitter`（键盘 ↑/↓）、下方时间线面板；详情栏左侧有竖向分隔条 `#aside-splitter`（键盘 ←/→）。两条分隔条松手后写入偏好，下次打开沿用。视图不滚动，页面不出现浏览器滚动条，时间线内的原生滚动条隐藏，横向由底部导航条 `#timeline-nav`、纵向由右侧导航条 `#timeline-vnav` 代替。标尺行吸顶，播放头的三角头 `#playhead-head` 画在标尺行里、竖线贯穿全部轨道，纵向滚动时两者都保持可见。
- 播放按钮：左边是图标与“播放/暂停”，右边用竖线隔开当前时间 / 总长（`.play-time`），像硬件面板上的读数；时间码不计入按钮的无障碍名称。
- 画幅：传输条右侧的菜单按钮，提供 16:9、9:16、4:3、3:4、1:1、4:5、21:9、2.39:1 与“自定义…”（就地输入“宽:高”，回车确认、Esc 放弃）；只在解锁后可改。
- 缩放（Premiere 键位）：默认适配全部；Ctrl 或 Alt+滚轮以指针处为锚缩放，滚轮横向滚动、Shift+滚轮纵向滚动，`=`/`-` 缩放、`\` 适配全部，最大每秒 400 像素；标尺主刻度间距不小于 80 像素并带细分刻度。片段按像素排布，参考画面沿片段横向平铺成胶片条。
- 时间线：解锁后拖动片段调整顺序（落点用 `#drop-mark` 指示），拖右边缘 `.clip-handle` 调整时长（0.1 秒吸附，拖动期间比例尺固定）；待定区的镜头拖入轨道时先给 2 秒，此占位并不代表用户确认。调整顺序后按新顺序重编显示镜号，沿用原有前缀与位数，稳定 ID 不变。键盘：Alt+←/→ 调整顺序，Shift+←/→ 时长 ±0.1 秒。
- 节奏预览：时间线上方的监视器按 `layout_aspect`（空时暂按 16:9，不代表用户确认）取景，按规格时长播放 `thumbnail`（没有则画合成占位）与一句话内容；`layout_camera` 的裁切框在镜内线性插值，裁切后按比例放入画幅、不足留黑，只有硬切，与 `scripts/layout_preview.py` 一致。静态图模拟不代表人物动作或动态验收。在标尺上按住拖动定位播放头（画面实时跟随）；点击片段只选中、不移动播放头；时间线视图里空格总是播放/暂停（捕获阶段处理，不会再触发聚焦中的按钮；文字输入、菜单、对话框除外），播放头走出可见区时自动翻页，离开时间线视图即停止播放。
- 镜头视频（v3 `timeline.video[0]`）：详情栏“关联资产”之后是“视频”块，只读与编辑共用同一套元素。未关联时是一个虚线按钮（解锁后为“关联视频…”）；已关联时按文件名自然排序列出全部版本（`versionsOf`：顶层字段是当前版本，其余在 `takes`），每行缩略图（取入点那一帧）与文件名，有多个版本时当前版本铺强调色淡底。解锁后点某一行即改用它（`useVersion`，与顶层字段连同 `id` 互换，可撤销），行尾垃圾桶移除该版本（移除当前版本时改用剩下的第一个），底部“添加版本…”打开可多选的系统对话框（`pickMedia` 带 `multiple`，宿主回 `items`），新版本只进候选、不自动切换，已存在的文件跳过。当前版本带声音开关（`soundButton`，与轨道开关一样写进文档，只读时变灰）。时间线镜头标签上有 `n/总数` 角标；右键镜头与标题旁“⋯”共用 `videoItems`：版本列表（当前打勾）、添加版本、用视频长度设为镜头时长、移除。入出点不再在详情栏填写，采用范围在时间线上裁剪。时间线主轨片段底部的覆盖条：实色为视频占用部分，斜纹为视频短于镜头的空缺，素材不可用时为警告色。
- 媒体播放：每个素材一个 `<video>`，叠在监视器画布上（`#monitor-media`），同一时刻只显示一个；播放位置仍以页面时钟为准，播放中媒体偏差超过 0.15 秒才重新定位，暂停时逐帧定位。镜头格内视频已结束的部分保持黑场；没有视频的镜头照旧画静态预演。
- 媒体宿主消息：页面发 `pickMedia`（`kind`、`request`）打开系统对话框，宿主回 `mediaPicked`（`status` 为 `picked`/`cancelled`/`unsupported`，以及相对路径 `source` 与可播放的 `url`）；页面发 `resolveMedia`（`sources`）换取地址，宿主回 `mediaUrls`（`source → url`，缺失或格式不支持为空字符串）。宿主收到 `ready` 前会丢弃其他消息，所以 `resolveMedia` 只在发出 `ready` 之后请求。WebView2 只认导航前设置的虚拟主机映射，宿主因此在启动时按盘符映射 `drive-<盘符>.kpl-media.local`。素材长度直接读 `<video>` 的元数据，基础编辑不依赖 ffmpeg。
- 时间线泳道：时间线左侧是轨道抬头（横向滚动时吸附），右侧是泳道。自上而下依次是字幕轨（`timeline.subtitles[0]` 最上，始终在视频轨之上）、自由视频轨（`video[1:]`，序号越大越靠上）、主轨 V1、音频轨 `audio`。抬头只显示轨道编号（`S1`、`V2`、`A1`，不显示 `name`），以及按轨道类型给出的开关：视频轨有画面（`hidden`，眼睛图标）与声音（`muted`，喇叭图标），音频轨只有声音，字幕轨只有画面；开关写进文档，只读时变灰不可点。抬头宽度 `--gutter`（默认 136px）可拖动右缘的 `#gutter-splitter` 调整（100–320px，偏好键 `gutterW`）。工具条 `+` 菜单可新建视频轨、音频轨、导入字幕，或把视频/音频插入播放头处的第一个空档。时间线总宽 = 抬头宽度 `--gutter` + 总时长 × 比例尺，播放头、点击定位与缩放锚点都按这个偏移换算。
- 字幕：只导入现成的 srt/lrc/ass 文件，宿主用 `Subtitle.cs` 解析（ASS 的 `\k` 卡拉 OK 标签与 LRC 的 `<mm:ss.xx>` 给出逐字时间），页面不生成文字、不做语音识别、不自动对齐音乐。页面发 `pickSubtitle`（`request`），宿主回 `subtitlePicked`（`status` 为 `picked`/`cancelled`/`invalid`，以及 `name`、`language`、`cues`）。监视器底部叠加最上面一条没关画面（`hidden`）的字幕轨里覆盖当前时间的条目；每条字幕轨在抬头单独开关显示，没有全局开关。`+` 菜单的“在播放头新建字幕”（`addCue`）手动加一条空字幕：播放头在空档里就从播放头起、长 2 秒且不越过下一条，落在已有字幕里时顺延到下一个空档。
- 自由轨编辑（沿用主轨的 0.1 秒吸附）：拖动条目移动、拖右缘手柄裁尾、方向键微调（Shift 走 1 秒）、`Delete` 删除、`Ctrl+K` 在播放头处分割；`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做（快照栈只留在内存里，最多 50 步，解锁编辑后可用）。同一轨道内条目不允许重叠，拖动与裁剪都会卡在相邻条目上。
- 媒体播放（自由轨）：`activeMedia` 汇总此刻要出声或出画的素材（主轨按镜头格，自由视频轨与音频轨按片段位置），`syncMedia` 让它们跟随时钟。画面只给最上面一条没关画面、此刻有片段的视频轨；声音各轨按自己的开关与音量同时播放；既不出画也不出声的素材暂停。
- 标记带（`#marker-band`，标尺下方，与标尺一起吸顶）：`markers` 的点标记是竖线加实色小旗，范围标记是一段色条；用户写的用 `--accent`，Agent 写的用 `--seg-camera`。解锁后按 `M` 或 `#marker-add` 在播放头加点标记，在空白处拖动画出范围标记，拖动标记移动、拖右缘 `.marker-handle` 调终点，`Delete` 删除；都进撤销栈。
- 详情栏对象：`detailSubject()` 按当前选中决定显示什么——选中标记显示标记面板，选中字幕条目显示字幕面板，否则显示镜头。字幕与标记的文字用同一个 `.detail-text` 输入框（只读与编辑共用），获得焦点时拍快照、失焦时有改动才压进撤销栈。点镜头会清掉泳道与标记的选中。
- 边缘拖动：自由轨片段、字幕、范围标记与主轨镜头两侧都有手柄（`data-handle` / `data-edge` 为 `start`、`end`）。自由轨片段裁开头时入点同步后移，不能早于素材开头；字幕裁剪时丢掉落在范围外的逐字时间。主轨镜头拖右缘改本镜时长；拖左缘默认移动与上一镜的切点（两镜此消彼长、总长不变，`resizeShot`），按住 `Alt` 或第一镜只改本镜时长。每次移动都从拖动开始时的状态重算。
- 吸附（偏好 `snap`，默认开，工具条磁铁或 `S`）：`snapTargets` 收集各轨条目边缘、镜头切点、标记与播放头，`settle` 在 8 像素内贴靠并显示 `#snap-line`；关闭时按 0.1 秒取整。主轨拖动只贴不会跟着动的目标。
- 联动（偏好 `link`，默认开，工具条链环）：`linkSnapshot` 拍下镜头开始时间与各条目位置，`applyLink` 让条目跟着它开始时所在的镜头走（镜头计划之后的跟着总长走），之后同一轨道若挤在一起按顺序往后推开。拖镜头边缘、Shift+←/→、待定镜头拖入、“用视频长度设为镜头时长”与表格里改时长（离开单元格时）都会联动；移动切点与调整镜头顺序不改总长，不联动。锁定的行不参与。
- 锁定（文档字段：轨道 `locked`、时间线 `markers_locked`）：抬头与标记带左侧的锁按钮，只在解锁编辑后可改。锁定行带斜纹底、条目变淡，不能拖动、裁剪、分割、删除或新增，详情栏文字只读；选中与画面/声音开关照常。
- 右键菜单（`setupContextMenu` / `contextItems`）：复用 `#popup-menu`，以右键位置为锚点，菜单项可带快捷键提示（`hint`）。片段与字幕：编辑文字、在此处分割、删除、锁定；标记：编辑说明、删除、锁定标记；主轨镜头：关联/替换视频、用视频长度设为镜头时长、移除视频、锁定；轨道抬头：画面/声音开关、锁定、清空、移除；空白泳道：在此处新建字幕、插入视频/音频、添加标记，再加轨道操作。“在此处”先把播放头移到右键的位置。
- 泳道重绘：`renderLanes` 与 `renderMarkers` 按 key（轨道 `kind:id`、条目 `data-id`、标记 `data-marker`）复用已有节点，`morph` 就地同步属性与子节点，所以选中、锁定、开关等状态切换的 CSS 过渡能在原节点上播放、焦点也不丢；新出现的条目与轨道用 `@starting-style` 淡入，删除的加 `.is-leaving` 淡出后再移除。抬头按钮不绑闭包，点击由 `setupLaneHeads` 在 `#lanes` 上委托处理（`data-act`：`hidden`/`muted`/`locked`/`more`），复用节点也不会拿到旧对象。“⋯”与开关一样只读时变灰。
- 选中互斥：选中泳道条目或标记时，时间线上的镜头让出高亮（表格行不变）；点镜头会清掉泳道与标记的选中。
- 抬头与泳道的分隔线是抬头向外 1 像素的阴影，与 0 秒刻度落在同一列像素上。详情栏的视频缩略图按地址缓存同一个 `<video>`（`thumbVideo`），解锁等整块重绘时不重新加载、不闪。
