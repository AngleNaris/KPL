KPL 规格编辑器

一个项目只有一份当前规格。此 Windows 编辑器用来查看和修改 .kpldoc；它仍是原型，请先使用合成文件确认本机运行正常。程序与可修改源码在此技能的 native-prototype 目录中，不需要原开发机的路径。

  1. 复制 examples/01_合成规格_v001_draft.kpldoc，双击副本。首次打开如需选择程序，请使用实际的共享编辑器。
  2. 点击“解锁编辑”，修改内容，按 Ctrl+S 或点击保存。解锁只是防误操作，并非加密。
  3. 关闭后重开，确认修改。若文件已在别处改动，编辑器会提示冲突；先核对实际文件，不要覆盖另一份修改。

表格与时间线

表格按镜头显示秒数、一句话内容、景别、镜头运动和关联素材数；详情中可查看描述和提示词。时间线按秒数排列，用参考图做静态预演，并非真实人物动作或最终视频。

没有画幅时预览暂按 16:9；将待定时长镜头拖入轨道会暂填 2 秒。这些占位都不等于你的决定，请明确核对。重排会改变显示镜号，原有素材或文档引用也需核对。

规则与联网说明

  • 镜头时长只精确到 0.1 秒，详细描述只概括画面、不超过 300 字；检查脚本会拒绝超出的内容，编辑器只在详情栏显示字数提示。旧文件里的多位小数时长，打开时会按累计切点规整显示，解锁并保存后才写回文件。
  • 镜头多、参考图大时，编辑器不直接载入原图，而是在后台把图片缩成缩略图，缓存在 %LOCALAPPDATA%\KPL\thumbs\（项目之外，可随时删除重建）；生成期间状态栏显示进度，没生成好的图只显示占位。
  • 编辑器启动时会在后台静默检查 GitHub 上是否有新版本，只提示，不会自动下载或安装；离线不影响使用。窗口大小和显示偏好保存在 %LOCALAPPDATA%\KPL\prefs.json。

HTML 查看副本

examples/02_合成规格_v001_draft.html 可用浏览器查看。它不会随规格自动同步，也不是第二份当前规格。需要时可导出新的查看副本，避免覆盖已有文件。

打开方式与范围

共享程序位于 bin/win-x64/KPL规格编辑器.exe；不必为每份文档复制程序。首次交付时可让 Agent 先检查当前桌面用户的关联：若尚未设置，会征求你同意后设置；若旧关联属于 KPL，会显示旧、新路径，只有你明确同意替换时才尝试修复。已有其他程序或 Windows 受保护选择时，不自动覆盖。设置后还会检查 Windows 实际解析的打开路径。

如果脚本被签名、策略或权限阻止，请在 Windows“设置 → 应用 → 默认应用”中查找 .kpldoc，按系统提示选择上面的编辑器；不要为了设置而绕过安全提示。程序需 Windows x64、现有 .NET Framework 4.8 与 WebView2 Runtime；这两个运行时不随包提供，也不会自动安装。
